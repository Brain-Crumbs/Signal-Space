# GROSS GitHub Actions

CI installs the locked Python dependencies, installs the repository in editable
mode, runs retained GROSS and reader-contract tests, verifies the active/archive
boundary and checks Markdown mathematics. No Node setup, npm task, browser build
or archived test suite runs.

The manual **Run experiment** workflow executes a selected locked GROSS recipe
through the same pipeline as `signal-space pipeline`. It uploads canonical
and reader evidence even on failure. Artifacts have finite retention; preserve
accepted evidence in durable storage before expiry. Full campaigns remain
subject to their registered resource and scientific prerequisite gates.

Test 8 quiet calibration is available from the CLI. Full G0–G9 exchange remains
blocked by its documented prerequisites; no workflow implies scientific readiness.
