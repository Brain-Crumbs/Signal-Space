# Experiment manifests

`setup-a.json` is a checked-in example of the `paper-i-experiment-v1` format. The complete inexpensive A–I smoke set is exposed by `smokeSetupIds` and `createSmokeDefinition` in `@signal-space/experiments`; those definitions intentionally reuse the small isolated/pair scenarios without duplicating nine large JSON files. They are wiring fixtures only, not research runs.
