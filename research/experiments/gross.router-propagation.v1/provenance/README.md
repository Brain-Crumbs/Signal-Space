# Publication provenance

The canonical run retains its original solver/analysis/report identity. `source-history.bundle` preserves the original local solver commit on top of main bc45f739fa9c15f2bffd10bc49a6e3f5c6db650c. The final GitHub tree may have a different publication commit when pushed with the GitHub app. This never relabels raw evidence.

`execution.json` records the local recipe and checksum of its generated source tarball. That tarball duplicates the Git tree and is not included in this repository copy; recover the exact source via the Git bundle. The untouched original local evidence package also retains it. Stage logs, locked plan/config and automated assessment are preserved here. The reader export uses the separately reviewed analysis.
