# Accepted experiment packages

Each accepted package lives at `<experiment-id>/<run-id>/` and follows `docs/research/artifact-contract.md`.

This foundation contains no accepted new-model experiment. Imported historical calculation material is stored under `research/source/` and is not relabeled as a conforming run package.

For new large runs, the full canonical package, reader PDFs, plot data and every figure format belong in run artifacts. Keep the reviewed Markdown, compact checks, canonical manifest and checksums, source revision, and an artifact index in Git. The index records file hashes, run and artifact IDs, retention date and a durable mirror when available. Never replace an expired artifact with unverified data or silently count a missing package as preserved evidence.
